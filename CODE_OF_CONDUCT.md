# Code of conduct

This is a small project. The rules are short.

## Do

- Be courteous. Assume the other person means well.
- Keep to the technical subject.
- Accept a "no". Not every idea fits this project.

## Do not

- Insult, harass, or attack a person.
- Post the private information of another person.
- Use sexual or violent language or images.

## If there is a problem

Report it to the maintainers in private, by email to jaklimoff@gmail.com. If the
report holds sensitive details, you may use a private security advisory on
GitHub instead. The
maintainers read every report and keep it private.

The maintainers can edit or remove a comment, close an issue, or block a person
from the project. A serious or repeated breach leads to a permanent block.

This code of conduct applies in the repository, in issues, in pull requests, and
in any space where a person speaks for the project.
